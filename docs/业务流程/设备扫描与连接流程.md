# 设备扫描与连接流程

## 📋 流程概述

本文档描述用户从启动扫描到成功连接 BLE 设备的完整流程。

## 🔄 完整流程图

```mermaid
sequenceDiagram
    participant User as 用户
    participant UI as React App
    participant IPC as Preload IPC
    participant BLE as BleService
    participant FSM as DeviceFSM
    participant Noble as noble
    participant Device as BLE 设备

    Note over User,Device: 1. 启动扫描
    User->>UI: 点击 "Start Scan"
    UI->>IPC: startScan()
    IPC->>BLE: ipcMain.handle
    BLE->>Noble: startScanningAsync()
    BLE->>BLE: startPresenceCheck()
    BLE-->>UI: { success: true }
    UI->>UI: setIsScanning(true)

    Note over User,Device: 2. 发现设备
    Device-->>Noble: BLE 广播
    Noble-->>BLE: 'discover' event
    BLE->>BLE: createDeviceFSM(peripheral)
    BLE->>FSM: new Sp51aDeviceFSM()
    BLE->>FSM: discover(peripheral)
    FSM->>FSM: idle → discovered
    BLE-->>UI: 'ble:device-found'
    UI->>UI: 更新设备列表

    Note over User,Device: 3. 用户选择连接
    User->>UI: 点击设备 🔋 按钮
    UI->>IPC: connectAndGetBattery(deviceId)
    IPC->>BLE: ipcMain.handle
    BLE->>Noble: stopScanningAsync()
    BLE->>FSM: connect()

    Note over User,Device: 4. FSM 连接流程
    FSM->>FSM: onConnectingGuard() 验证
    FSM->>FSM: discovered → connecting
    FSM->>Noble: peripheral.connectAsync()
    Noble->>Device: BLE 连接请求
    Device-->>Noble: 连接成功
    FSM->>FSM: send(CONNECT_SUCCESS)
    FSM->>FSM: connecting → connected
    FSM->>FSM: onConnectedEntry() [打印时间]

    Note over User,Device: 5. 自动读取电量 (SP51A)
    FSM->>FSM: readBattery()
    Note right of FSM: 保持 connected 状态
    FSM->>Noble: discoverServicesAsync()
    FSM->>Noble: readCharacteristic(0x2A19)
    Noble->>Device: 读取电量
    Device-->>Noble: 电量数据
    FSM->>FSM: ctx.batteryLevel = 63

    Note over User,Device: 6. 返回结果
    BLE-->>UI: { success: true, level: 63 }
    UI->>UI: setBatteryLevel(63)
    UI->>UI: 显示电量 63%
```

              └─────────► CONNECT ─────────►└─────────► SUCCESS ─────────►│
                          ↑                              ↑
                     pre: 停止扫描                  post: 注册断开监听
                     pre: 检查蓝牙状态              post: 读取电量

```mermaid
stateDiagram-v2
    [*] --> idle

    idle --> discovered: DISCOVER
    note right of discovered: 记录设备信息\n更新 lastSeen

    discovered --> connecting: CONNECT
    note right of connecting: Guard: 验证设备\n Entry: 执行连接

    connecting --> connected: CONNECT_SUCCESS
    connecting --> discovered: CONNECT_FAIL
    note right of connected: Entry: 打印时间\n readBattery() 可调用

    connected --> disconnecting: DISCONNECT
    connected --> discovered: AUTO_DISCONNECT

    disconnecting --> idle: DISCONNECT_DONE
```

> **注意**：`readBattery()` 是在 `connected` 状态下直接调用的方法，不触发状态转换。

## 🔧 关键代码路径

### 1. 启动扫描

```typescript
// UI (App.tsx)
const handleStartScan = async () => {
  const result = await window.ble.startScan()
  if (result.success) setIsScanning(true)
}

// BleService (ble.ts)
async startScan(): Promise<ScanResult> {
  await noble.startScanningAsync([], true)  // 允许重复
  this.startPresenceCheck()                  // 启动存在性检测
  return { success: true }
}
```

### 2. 设备发现

```typescript
// BleService
noble.on('discover', (peripheral) => {
  // 创建/获取 FSM
  let fsm = this.deviceFSMs.get(peripheral.id)
  if (!fsm) {
    fsm = createDeviceFSM(peripheral) // 返回 Sp51aDeviceFSM 或 undefined
    if (fsm) this.deviceFSMs.set(peripheral.id, fsm)
  }

  // 触发 DISCOVER 事件
  fsm?.discover(peripheral)

  // 通知 UI
  this.mainWindow?.webContents.send('ble:device-found', {
    id: peripheral.id,
    name: peripheral.advertisement.localName || 'Unknown',
    rssi: peripheral.rssi,
    connectable: peripheral.connectable
  })
})
```

### 3. 连接与读取

```typescript
// BleService
async connectAndGetBattery(deviceId: string): Promise<BatteryResult> {
  const fsm = this.deviceFSMs.get(deviceId)

  // 停止扫描
  await noble.stopScanningAsync()

  // 连接 (SP51A 会在 onConnectedEntry 中自动 readBattery)
  const connectSuccess = await fsm.connect()

  // 等待电量读取完成
  await new Promise(r => setTimeout(r, 500))

  const ctx = fsm.getContext()
  return {
    success: ctx.batteryLevel !== null,
    level: ctx.batteryLevel ?? undefined
  }
}
```

### 4. SP51A 自动读取电量

```typescript
// Sp51aDeviceFSM
protected async onConnectedEntry(ctx, event): Promise<void> {
  await super.onConnectedEntry(ctx, event)

  // 仅在首次连接时自动读取
  if (event === BleEvents.CONNECT_SUCCESS) {
    console.log(`[SP51A] Connected at ${new Date().toLocaleString()}`)
    await this.readBattery()  // 触发 READ_BATTERY
  }
}
```

## ⚠️ 错误处理

### 连接失败

```mermaid
sequenceDiagram
    FSM->>Noble: connectAsync()
    Noble-->>FSM: Error
    FSM->>FSM: ctx.error = message
    FSM->>FSM: send(CONNECT_FAIL)
    FSM->>FSM: connecting → discovered
    BLE-->>UI: { success: false, error: "..." }
    UI->>UI: setError(message)
```

### 设备丢失

```mermaid
sequenceDiagram
    Note over BLE: 5秒内未收到广播
    BLE->>BLE: checkDevicePresence()
    BLE->>FSM: isStale(5000) == true
    BLE->>FSM: markLost()
    FSM->>FSM: discovered → lost
    BLE-->>UI: 'ble:device-lost'
    UI->>UI: 从列表移除设备
```

### 自动断开

```mermaid
sequenceDiagram
    Device-->>Noble: 断开连接
    Noble-->>FSM: 'disconnect' event
    FSM->>FSM: send(AUTO_DISCONNECT)
    FSM->>FSM: connected → discovered
    BLE-->>UI: 'ble:connection-state'
    UI->>UI: setConnectedDeviceId(null)
    UI->>UI: setError("Device disconnected")
```

## 📝 配置参数

| 参数                    | 值     | 说明              |
| ----------------------- | ------ | ----------------- |
| `DEVICE_LOST_TIMEOUT`   | 5000ms | 设备消失判定时间  |
| `DEVICE_CHECK_INTERVAL` | 1000ms | 存在性检测间隔    |
| 电量读取等待            | 500ms  | 等待 FSM 完成读取 |
